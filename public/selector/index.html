* + * 와 :has()

CSS 선택자 두 개를 공부하면서 적은 것. 2026년 10월.

이 페이지도 이 두 개로만 짰다. 자바스크립트 없음. 왼쪽 아래 「간격 보기」를 켜면 * + *가 만든 여백이 전부 빗금으로 보인다.

* + *

A + B는 A 바로 뒤에 붙은 B. 둘 다 *로 두면 앞에 형제가 있는 요소 전부가 걸린다. 첫째만 빠진다.

.stack > * + * {
  margin-top: 1em;
}
  +----------+
  | A        |  ← 첫째. 안 걸림
  |//////////|  ← 여기만 margin
  | B        |
  |//////////|
  | C        |
  +----------+  ← 끝에 남는 여백 없음

모양이 멍한 부엉이 눈 같다고 Heydon Pickering이 lobotomized owl이라고 불렀다(2014).

margin-bottom이랑 뭐가 다른가

점선이 부모 끝. 왼쪽은 C 밑에 여백이 남아서 밖으로 샌다.

간격을 관계로 적는다

제일 마음에 든 부분. “제목은 아래 24px”이 아니라 “제목 다음은 붙이고, 제목 앞은 띄운다”로 적는다. 클래스를 안 달아도 글 순서만으로 리듬이 생긴다.

.rhythm > * + h4         { --gap: 1.6em }
.rhythm > h4 + *         { --gap: 0 }
.rhythm > * + blockquote { --gap: 1em }

:has()

A:has(B)는 B를 안에 가진 A. 원래 CSS는 바깥에서 안으로만 내려갈 수 있었는데 이건 거꾸로 올라온다. 부모 선택자는 안 된다는 게 오래된 상식이었다. 2023년 12월 Firefox 121까지 들어오면서 이제 다 된다.

안에 든 체크로 바깥 바꾸기

label:has(input:checked) { background: yellow }
.pick:has(input:checked)
  label:not(:has(input:checked)) { color: gray }

두 번째 줄이 좋다. 하나라도 골랐으면 나머지를 흐리게. 예전엔 JS로 했을 일.

폼

.f:has(input:user-invalid) .err { display: block }
form:has(:invalid) button { opacity: .4 }

@가 빠졌다.

:invalid 대신 :user-invalid를 썼다. 앞의 것은 아무것도 안 쳤는데도 처음부터 빨갛다.

개수 세기

:has(> :nth-child(3)) = 자식이 3개 이상인가. 화면 폭 말고 내용 양에 반응한다.

.qty                      { 1단 }
.qty:has(> :nth-child(3)) { 2단 }
.qty:has(> :nth-child(6)) { 3단 }

뒤를 보고 앞 고르기

+는 뒤만 볼 수 있었는데 :has(+ …)로 싸면 앞을 고를 수 있다. 제목 다음에 바로 또 제목이면 내용이 빈 것.

최종

같이 쓰기 (이 페이지)

「간격 보기」 체크박스는 구석에 하나 있을 뿐인데 body가 그걸 품고 있으니 페이지 전체 스위치가 된다.

body:has(#xray:checked) .stack > * + *::before {
  height: var(--band);
  background: 빗금;
}

만들다 걸린 것 두 개.

① 간격 값 --gap이 안쪽 스택으로 새지 않게 @property로 상속을 껐더니 빗금 높이가 0이 됐다. ::before도 자식이라 못 받은 거였다. 상속되는 --band에 한 번 옮겨 담아서 해결.

② 섹션 사이가 다닥다닥 붙었다. 섹션이 자기 안쪽용으로 정한 --space가 섹션 자신의 위 여백에도 쓰였다. 바깥 간격은 main > * + *에서 따로 주는 걸로.

메모

— :has()는 보이는지가 아니라 DOM에 있는지를 본다. 숨긴 자식도 걸리고 :nth-child에도 세어진다.

— :has() 안에 :has()는 못 넣는다. ::before 같은 것도.

— 명시도는 괄호 안에서 제일 센 것을 따른다. .a:has(#b)는 id급이라 나중에 덮기 귀찮다.

— 반대로 *는 0이라서 .stack > * + *는 클래스 하나 무게. 예외 규칙으로 덮기 쉽다.

— flex·grid 안이면 그냥 gap. 부엉이는 글처럼 흐르는 곳, 관계마다 간격이 다를 때.
