* + *:has()

형제 사이에만 간격을 주는 선택자와, 안을 들여다보고 바깥을 고르는 선택자. 공부한 내용을 정리했습니다. 이 페이지의 간격과 상태 변화도 전부 이 두 선택자로 만들었고, 자바스크립트는 한 줄도 없습니다.

오른쪽 아래 간격 보기를 켜면 페이지 전체의 * + * 여백이 빗금으로 드러납니다.

부엉이 선택자 * + *

2014년 Heydon Pickering이 붙인 이름입니다. * + *가 멍하니 쳐다보는 부엉이 눈처럼 생겨서 lobotomized owl이라고 불러요.

A + B는 “A 바로 뒤에 오는 B”입니다. 둘 다 *니까 뜻은 바로 앞에 형제가 있는 모든 요소. 첫 번째 자식만 빼고 전부 잡힙니다.

.stack > * + * {
  margin-block-start: var(--space);
}

그래서 간격이 요소 사이에만 생깁니다. 모든 요소에 margin-bottom을 주는 방식과 나란히 놓고 보면 차이가 보여요.

간격은 요소가 아니라 관계에 붙는다

여기서 핵심 발상이 나옵니다. 여백을 “제목은 아래 24px” 같은 요소의 속성으로 보지 않고, “제목 다음에 오는 것은 붙이고, 제목 앞은 크게 띄운다”는 관계의 규칙으로 씁니다.

.rhythm > * + * { --gap: .6rem }
.rhythm > * + h4 { --gap: 2rem }
.rhythm > h4 + * { --gap: .25rem }
.rhythm > * + blockquote { --gap: 1.25rem }

빠졌던 것: 숨긴 첫 요소

안을 보고 바깥을 고르는 :has()

CSS는 원래 바깥에서 안쪽으로만 내려가며 골랐습니다. A:has(B)는 거꾸로 B를 품고 있는 A를 고릅니다. 오랫동안 “부모 선택자는 불가능하다”던 기능이고, 2023년 말 Firefox 121을 마지막으로 주요 브라우저가 모두 지원합니다.

자식의 상태로 부모 꾸미기

체크박스는 :checked 상태를 가지지만 그 상태로 꾸밀 수 있는 건 체크박스 자신과 뒤 형제뿐이었습니다. :has()를 쓰면 체크박스를 품은 카드 전체를 바꿀 수 있어요.

.option:has(input:checked) { border-color: blue }

/* 하나라도 고르면, 고르지 않은 나머지를 흐리게 */
.options:has(input:checked)
  .option:not(:has(input:checked)) { opacity: .45 }

폼 전체가 입력 상태를 안다

.field:has(input:user-invalid) .msg { display: block }
form:has(:invalid) .send { background: gray }

@가 들어간 이메일 주소를 입력하세요.

:user-invalid는 사용자가 한 번 건드린 뒤에만 틀렸다고 표시해서, 처음부터 빨간 칸이 뜨지 않습니다.

개수를 세서 레이아웃 바꾸기

:has(> :nth-child(n))은 “자식이 n개 이상인가”라는 질문이 됩니다. 미디어 쿼리가 화면 폭에 반응한다면 이건 내용의 양에 반응합니다.

.qty                          { 1단 }
.qty:has(> :nth-child(3))     { 2단 }
.qty:has(> :nth-child(6))     { 3단 }

뒤를 보고 앞을 고르기

+는 뒤쪽만 볼 수 있었는데, :has(+ …)로 감싸면 “다음 형제가 이런 요소인 앞 요소”가 됩니다. 제목 바로 뒤에 또 제목이 오면 그 사이 내용이 비었다는 뜻이니 표시해 봤습니다.

h4:has(+ h4), h4:last-child { /* 내용 없는 제목 */ }

오른쪽 아래 토글이 그 예입니다. 체크박스는 페이지 구석에 하나 있을 뿐인데, body가 그걸 품고 있으니 페이지 전체의 상태 스위치가 됩니다.

body:has(#xray:checked) .stack > * + *::before {
  height: var(--band); /* 여백 높이만큼 */
  background: 빗금;
}

여백은 원래 칠할 수 없는 빈 공간이라, 각 요소 위에 여백과 같은 높이의 의사요소를 붙여 칠했습니다. 관계마다 간격이 다르니 간격은 --gap 변수 하나로 정하고, 중첩된 스택에 값이 새지 않도록 @property로 inherits: false를 걸었습니다.

그런데 빗금 높이가 0으로 나왔습니다. ::before도 그 요소의 자식이라 상속을 끈 --gap을 받지 못한 거예요. 상속되는 --band에 값을 한 번 옮겨 담아서 해결했습니다.

섹션 사이 간격도 한 번 꼬였습니다. 섹션이 자기 자식 간격용으로 --space를 다시 정하자, 그 값이 섹션 자신의 위쪽 여백에도 쓰였거든요. 바깥 간격은 main > * + *에서 따로 정하는 것으로 고쳤습니다.

헷갈렸던 것들

  • :has()는 요소가 DOM에 있는지를 봅니다. 보이는지가 아닙니다. display: none인 자식도 매치되고, :nth-child로 셀 때도 포함됩니다.
  • :has() 안에 :has()를 넣을 수 없고, ::before 같은 의사요소도 넣을 수 없습니다.
  • 명시도는 괄호 안에서 가장 센 선택자를 따릅니다. .a:has(#b)는 id 하나만큼 세져서 나중에 덮어쓰기 어렵습니다.
  • 반대로 *는 명시도가 0이라 .stack > * + *는 클래스 하나 수준입니다. 가벼워서 예외 규칙으로 덮기 쉽습니다.
  • flex·grid 안에서는 gap이 더 간단합니다. 부엉이는 글처럼 블록이 흐르는 곳, 그리고 관계마다 간격을 다르게 줄 때 강합니다.
